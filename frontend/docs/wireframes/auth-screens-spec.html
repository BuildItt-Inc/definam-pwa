Auth Rules Summary — For Dev Team
User TypeHow They RegisterHow They LoginAccess Code RoleDevice Handling
Individual Student username + password + access code (web, after payment) username + password only One-time use at registration. Then retired (status → active). org_id = NULL. Standard session. No device lock.
Org Student (School) No registration. System auto-creates account on first code use. Access code only. Always. No username, no password. Permanent login credential. org_id = school_id. Never expires unless revoked by admin. device_fingerprint stored on first use. New device → old session revoked, new fingerprint stored.
School Admin System creates account after org payment. Email = username. Temp password sent by email. username (school email) + password. Must change password on first login. No access code involved. Standard session. No device lock.
