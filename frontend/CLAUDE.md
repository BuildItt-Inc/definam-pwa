# DefinAm Frontend — Standing Instructions

## Documentation habit
After completing any task that adds, changes, or removes files,
always produce a short markdown summary of what was done and
where the files live. Save it to docs/ using the pattern
docs/WEEK{n}_{TASK_NAME}.md — matching the existing docs already
in this repo (see docs/WEEK1_AUTH_SCREENS.md,
docs/WEEK2_F1_STUDENT_SCREENS.md as examples of the expected format).

Include: what was audited/built, which files changed, what was
found or fixed, and any gaps or follow-ups still needed.
